# Undo a mistake

Every earlier version of a file is kept.

## Put back an earlier version of a file

1. Open the file on GitHub.
2. Click **History** near the top right of the file.
3. Find the version from before the mistake, and click the **`<>`** button on its row.
4. Click the **copy icon** (Copy raw file).
5. Open the current file again from its folder, and click the **pencil icon** (Edit this file).
6. Select all the text, delete it and paste the copied version in.
7. Click **Commit changes...**, then **Commit changes**.

A few minutes later, check the page on the website.

## Bring back a deleted file

Contact your support contact and tell them which file it was. Nothing is lost, as earlier versions are kept, but this takes a few more technical steps.
