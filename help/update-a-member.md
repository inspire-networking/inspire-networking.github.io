# Update a member

1. Open the [members folder](https://github.com/inspire-networking/inspire-networking.github.io/tree/main/_members) and click the member's file.
2. Click the **pencil icon** (Edit this file).
3. Change the details inside the quote marks, or the description under the second `---`.
4. Click **Commit changes...**, then **Commit changes**.

A few minutes later, check the [Members page](https://inspire-networking.github.io/inspire-members/).

**New photo or logo:** upload it with the same file name as the old one to replace it. See [Add or replace a photo](add-or-replace-a-photo.md).
