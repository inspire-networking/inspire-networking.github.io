# Inspire Networking Group website

This is where the Inspire website is kept. Each page, member and article is one text file. When you save a change here, the website updates by itself, usually within a few minutes.

**You only need a web browser and your GitHub sign-in.**

## Before your first edit

Do these once, in your GitHub account [email settings](https://github.com/settings/emails):

1. Check your email address shows as verified.
2. Tick **Keep my email addresses private**. Changes to this site are public, so this keeps your address out of them.

## Where things are

| Folder or file | What's in it |
|---|---|
| `pages` | One file for each page of the site |
| `_members` | One file for each member |
| `_news` | One file for each article |
| `images` | All the photos and logos |
| `_data/settings.yml` | Meeting details and social media links |
| `help` | These guides |

**Please leave everything else alone.** The other files run the site's design.

## How saving works

There's no approval step: once you save, the change goes live. Every earlier version is kept, so a mistake can always be put right.

If a change has a problem, the site keeps showing the previous version and GitHub emails you. See [When something goes wrong](help/when-something-goes-wrong.md).
